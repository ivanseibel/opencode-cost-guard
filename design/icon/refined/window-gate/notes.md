# Refined 3 — Window + gate fusion

**Idea.** Concept 1's window keeps its green and red fields, but an arched threshold (200 px wide, r100) is cut up from the bottom edge, borrowing concept 3's silhouette. The diagonal slit now starts at the arch springline and runs to the right edge, so the red field becomes a single slanted-topped pillar beside the doorway while green forms the lintel and left pillar. The doorway is navy tile showing through, which fixes concept 3's off-white tile vanishing on light backgrounds.

**Changed from concept 1.** The slit is shortened to start at the gate, the window gains the arched cut-out, and the colour ratio shifts toward green. Still tile + 2 shapes, no gradient.

**Glyph.** The gate silhouette alone: a rounded 12×14 pt block with a 4.4 pt arched door cut from the bottom (18 pt grid). The slit is dropped from the glyph so it stays one clean shape.

**16 px check.** Icon: the arch and the red pillar read at 32 px; at 16 px the arch is about 3 px wide and the red pillar about 2 px, so the slit detail is lost but the gate shape remains. Glyph: strongest silhouette of the three at 16 px, single shape, no hairlines.

**Risk.** The arch-in-block form can be read as the letter "n" at small sizes. Worth a look before choosing it.

**Light/dark.** Navy tile holds on both. The glyph is a single solid shape and template-safe.
